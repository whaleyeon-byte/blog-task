# 이슈 쇼츠 메이커 — Claude Code 작업 규칙

사용자가 **"이슈 쇼츠 만들어줘"** (또는 "쇼츠 만들어줘", "경제 쇼츠 하나", "○○ 주제로 쇼츠")라고 하면
아래 절차를 처음부터 끝까지 진행해 `output/` 에 mp4 를 만든다. 업로드는 하지 않는다(사용자가 직접).

## 0. 환경 확인 (매번, 10초)
- 파이썬: Windows `.venv/Scripts/python.exe`, 그 외 `.venv/bin/python`. 둘 다 없으면 → "setup_windows.bat 을 먼저 실행해 주세요" 안내 후 중단.
- `config.json` 없으면 같은 안내. (값이 비어 있는 건 괜찮음 — 기본값으로 동작)

## 1. 주제 고르기 (사용자가 주제를 안 줬을 때)
1. WebSearch 로 **최근 48시간 한국 이슈**를 찾는다. 검색 예: "오늘 경제 뉴스", "금리 환율 오늘", "정부 지원금 신청 시작", "IT 신제품 발표", "실시간 이슈".
2. 후보 5개를 짧은 표로 보여 준다: 주제 / category / 화제성(상중하) / 광고단가(상중하) / 위험도.
3. **섞는 비율**: `output/*/script.json` 의 최근 5개 category 를 보고,
   - 고단가(economy, stock, realestate, policy, it, car, health) 약 70%
   - 화제성(society, entertainment, sports) 약 30%
   가 되도록 1순위를 **자동으로 골라 바로 진행**한다(사용자는 '딸깍'을 원함). 다른 후보는 보고 때 한 줄로 알려 준다.
4. 제외: 사건·사고 피해자/미성년자 중심 이슈, 수사 중 개인 실명 저격, 선거·정당 편들기, 확인 안 된 루머·찌라시.

## 2. 사실 확인 (생략 금지)
- 언론사 **2곳 이상**에서 같은 내용을 확인하고 **기사 날짜**를 확인한다. 오래된 기사 재탕 금지.
- 숫자·날짜·기관명·인명은 원문과 대조. 확인 안 되는 내용은 대본에서 뺀다.
- 수사·재판 중인 일은 "혐의", "~라고 밝혔다"처럼 쓰고 단정하지 않는다.

## 3. 대본 작성 → `scripts/YYYY-MM-DD_<영문slug>.json`
분량: **장면 6~8개, 공백 뺀 낭독 글자 합계 230~320자** (≈ 35~50초). 60초를 넘기지 않는다.
**장면 하나는 1~2문장(3~6초)**. 화면이 오래 멈춰 있으면 이탈한다.

```json
{
  "title": "본문 장면 상단에 고정되는 제목 (16자 안팎, 2줄 이내)",
  "title_highlight": ["제목 중 노란색으로 칠할 단어"],
  "slug": "fed_rate_cut",
  "category": "economy",
  "badge": "오늘의 환율",
  "youtube_title": "유튜브 업로드 제목 (40자 이내, 궁금증 유발, 낚시·허위 금지)",
  "description": "2~3문장 요약. 투자/의료 주제면 '정보 제공 목적' 문구 포함.",
  "hashtags": ["환율", "경제뉴스"],
  "sources": ["언론사 - 기사 제목 (날짜) - URL", "..."],
  "source_label": "머니투데이·연합뉴스",
  "scenes": [ ...아래 장면 종류 참고... ]
}
```

### 장면 종류 (`layout`) — 같은 종류를 2번 연속 쓰지 말 것
| layout | 언제 | 필요한 값 |
|---|---|---|
| `hook` (첫 장면 자동) | 노란 집중선 + 거대한 글씨. **썸네일 역할** | `lines`: 2줄 (각 2~6자, 예 `["환율","1340원대"]`), `sticker`(선택, 4자 이내 예 `"3일째"`) |
| `number` | 핵심 수치. 숫자가 카운트업됨 | `number`(`"1338.8"`), `unit`(`"원"`/`"%"`), `label`(`"11월 5일 기준"`), `delta`(선택 `"▼ 3.7원"`/`"▲ 0.25%p"`) |
| `vs` | 엇갈리는 전망·비교. VS 쾅 + 화면 흔들림 | `left`/`right`: `{"label":"우리은행","value":"1370","unit":"원","arrow":"up/down"}` |
| `point` | 이유·방법 나열 ①②③ | `index`(1,2,3…), `caption`(12자 이내) |
| `text` | 그 밖의 핵심 한 줄 | `caption`(14자 이내) |
| `image` | 사용자가 준 이미지가 있을 때만 | `image`, `caption`, `image_credit` |
| `cta` (마지막 자동) | 정리 + 구독 버튼 | `lines`: 2줄 |

모든 장면 공통: `text`(내레이션, 필수), `highlight`(text 에 글자 그대로 있는 강조어 1~3개), `sfx`(`alert|whoosh|pop|ding|boom|none`, 생략 시 자동).
숫자는 **기사로 확인한 값만** `number`/`vs` 에 넣는다. 추정치·예시 값 금지. 그래프용 가짜 데이터 금지.

### 시청 유지 공식 (반드시 지킬 것)
1. **첫 1초에 결론의 일부**: 인사·자기소개·"오늘은 ~를 알아볼게요" 금지. 첫 문장에 숫자나 반전.
2. **궁금증 남기기**: 첫 장면에서 질문을 던지고, 답은 뒤쪽 장면에서 준다 ("연말엔 오를까요?" → 4번째 장면에서 전망).
3. **진행 신호**: "첫 번째", "그런데", "반대로" 같은 말로 장면을 넘긴다.
4. **나와 연결**: 끝에서 두 번째 장면까지 "내 지갑·생활에 무슨 영향"을 한 번은 말한다.
5. **마지막은 짧게**: 행동 한 가지 + "구독". 마지막 문장이 첫 장면과 이어지면 반복 재생에 유리.

**문장 규칙 (TTS 가 자연스럽게 읽도록)**
- 한 문장 25자 안팎, 구어체("~입니다", "~거든요"). 괄호·슬래시·이모지 금지.
- 영문 약어는 한 번은 풀어서(예: "연준, 미국 중앙은행"). 큰 숫자는 "1조 2천억 원", 소수는 "1338원 80전"처럼 읽기 쉽게.

**금지**
- 기사 사진·방송 캡처·연예인/인물 사진·로고 사용 금지 (저작권·초상권). `image` 는 사용자가 `assets/images/` 에 직접 넣은 파일만.
- 투자 권유("지금 사세요"), 의료 효능 단정, 비방·혐오 표현, 허위·과장 제목.
- 예전 정지 카드 디자인을 원하면 최상위에 `"style": "card"`.

예시: `scripts/2026-11-05_krw_usd_motion.json`

## 4. 영상 만들기
```bash
.venv/Scripts/python.exe make_short.py scripts/<파일>.json     # Windows
.venv/bin/python make_short.py scripts/<파일>.json             # mac/linux
```
- 노트북에서 3~5분 걸릴 수 있으니 Bash timeout 을 600000 으로 준다.
- 네트워크 없이 시험만 할 때: 뒤에 `--engine dummy` (무음 음성).

## 5. 오류가 나면
- `[오류] 대본 검증 실패` → JSON 을 고치고 다시 실행.
- `음성 생성 3회 실패` → 인터넷/목소리 이름 확인. 1회 재시도 후에도 실패하면 중단하고 사용자에게 보고.
- `ffmpeg 을 찾지 못했습니다` / 폰트 오류 → setup_windows.bat 재실행 안내.
- **같은 오류가 2번 나면 더 시도하지 말고** 무엇이 성공했고 어디서 막혔는지 보고한다.

## 6. 완료 보고 (이 형식으로)
- 📁 파일: `output/<폴더>/short.mp4` (길이 N초), 썸네일 후보 `cover.png`, 업로드 정보 `upload.txt`
- 주제 / 선정 이유(화제성·단가) / 다른 후보 한 줄
- 사실 확인: 사용한 출처 2곳 이상 + 날짜
- 업로드 전에 사람이 볼 것: 수치 재확인 필요한 부분, 민감 표현 여부
- 유튜브 제목 · 설명 · 해시태그 (upload.txt 내용 그대로)
